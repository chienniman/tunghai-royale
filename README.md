# 東海大逃殺 Tunghai Royale

以**真實東海大學校園**為地圖的網頁版大逃殺遊戲，用瀏覽器就能玩，不用安裝。

> 目前版本：**v0.6 值夜**。這一版把遊戲寫成一個有頭有尾的夜晚：你是颱風天被排去教堂值班的新生，從一張舊照片開始，到橋上做出選擇為止。電腦和手機（橫向全螢幕）都能玩。

## 劇本

**民國一一四年九月二十二日，颱風警報發布後。** 你是今年的新生，工讀第一天被分配到路思義教堂整理詩歌本。交班的警衛伍伯只交代一句：天黑以後，約農路下面那座橋不要走。

故事分七章，由你找到的東西推進，世界會跟著變：

| 章 | 你找到 | 接著發生 |
|---|---|---|
| 序章　值夜 | — | 開場；室友阿哲開始傳訊息 |
| 一　她的名字 | 詩歌本裡的照片 | — |
| 二　四百二十塊 | 宿舍窗台下的日記 | 你闔上日記，天已經黑了；一個不該存在的號碼傳訊息給你 |
| 三　沒有人把它們放在一起看 | 牧場的簽到簿 | 旁邊的收音機自己打開，播的是五十年前的颱風警報 |
| 四　限時 | 圖書館的舊校刊 | 全校停電 |
| 五　八百公尺 | 郵局退回的信 | 遠處的公共電話響了。你可以去接 |
| 終章　橋 | 相思林裡的戒指 | 颱風回來了；她不再攻擊你，走在前面帶路 |

**三條時間線**

- **過去**（民國六十四年）：六樣遺物拼出颱風夜的真相。
- **現在**（民國一一四年）：三個聲音——傳訊息的室友阿哲、用「未知號碼」傳訊息的她、以及每一章都在下一個地點前面等你的警衛**伍伯**。他知道的比他說的多；每一章跟他說話，他會多說一點，到第四章他會說出五十年沒說的事。有他在的地方，她不靠近。
- **未來**（民國一六四年）：橋上的選擇各有一段「五十年後」。聽完伍伯的話，會多出第四個選擇。

進度存在瀏覽器裡；網址加 `?reset=1` 重來。人物與情節皆為虛構；「女鬼橋」是地圖資料裡真實存在的地名。

## 可以互動的東西（按 `E`）

校園裡有三百多個、二十一種：

| 物件 | 作用 |
|---|---|
| 故事碎片 | 藍白色光柱。讀完推進章節 |
| 伍伯 | 每章一段對話；他身邊是安全的 |
| 女鬼橋 | 終點。要晚上才能上去 |
| 土地公廟 | 供食物、抽籤（預告結局）、得平安符；廟周圍女鬼和阿飄不靠近 |
| 路燈開關 | 點亮 75 秒，燈下女鬼和阿飄不靠近 |
| 配電箱 | 停電時扳回去，提前復電 |
| 公共電話 | 平常只有風聲；第五章有一通你可以接 |
| 收音機 | 轉開 40 秒，把聽聲音的殭屍引過去 |
| 腳踏車 | 騎上去，速度是跑步的一倍半；不能開槍，而且有聲音 |
| 販賣機 | 掉一罐奶茶（補血），或卡住——踹它會發出聲音 |
| 紙箱、置物櫃、垃圾桶 | 按住翻找 |
| 公佈欄 | 每種鬼怪的規則 |
| 長椅 | 坐下回血 |
| 飲水機 | 喝水回一點血 |
| 教堂的鐘 | 白天敲直接入夜；晚上敲會驚動所有鬼怪 |
| 貓 | 可以摸。她靠近的時候，貓會先知道 |
| 乳牛 | 在牧場。可以摸，可以擠一點牛奶 |
| 郵筒、石碑、公車站牌 | 看一看，各有幾句話；五塊石碑各寫著不同的東西 |

按 `J` 開筆記本：過去、現在（含手機訊息）、未來三欄，加上讀過的怪談。

## 玩法

- **晝夜循環**：一天約 10 分鐘。白天搜刮物資、練槍；黃昏後天色轉暗、建築亮燈、手電筒自動打開，天亮時鬼怪全數消散。
- **女鬼**：又高又瘦、脖子歪斷、濕髮蓋臉。她不會直接衝過來，而是遠遠站著盯你——你一直視她，她就憑空消失，再出現時更近，而且總在你看不到的地方；你沒看她的時候，她才一格一格逼近，最後站在你背後等你回頭。她靠近時手電筒會閃爍、畫面起雜訊、心跳加快。回頭看到她、或開槍打她，她就撲臉。護甲擋不住鬼，只能打散她或逃到天亮。
- **阿飄**：成群結隊飄過來咬人，血少但煩。
- **殭屍**：看不見，靠聲音找人。跑步和開槍會把牠引過來（槍聲 75 公尺外都聽得到）；蹲著走或站著不動牠就會跟丟。血很厚，貼著符的頭是弱點。
- **吊死鬼**：掛在樹上，你從底下走過就掉下來掐住你，動彈不得。聽到繩子吱嘎聲就抬頭看，被掐住就近距離開槍把它打掉。
- **紅衣小女孩**：在前面邊笑邊跑。追上她，你就會被「牽走」——醒來人在兩百公尺外，手電筒還打不開。別跟。

每種鬼怪只有一條規則，也都有破解法。

## 突發事件

每隔一段時間會隨機發生一件事，每一局都不一樣：

| 事件 | 時段 | 發生什麼 |
|---|---|---|
| 空投補給 | 日夜 | 補給箱掛著降落傘落下，小地圖有標記，裡面是高級武器與護甲 |
| 午後雷陣雨 | 日夜 | 下雨、天色變暗、打雷閃電 |
| 停電 | 夜 | 全校燈光與手電筒熄滅十秒，阿飄趁機湧上來 |
| 鬼打牆 | 夜 | 濃霧、羅盤亂轉、小地圖失效 |
| 百鬼夜行 | 夜 | 一大群阿飄和殭屍衝著你來，撐過去有空投 |
| 紅衣小女孩 | 夜 | 見上 |
| 鬼火引路 | 夜 | 跟著藍色鬼火走，盡頭有一批物資 |
| 子時鐘聲 | 午夜 | 鐘響，所有鬼怪立刻出動 |
| 血月 | 部分夜晚 | 整晚鬼怪更快，天空泛紅 |

- **5 種武器**：手槍、衝鋒槍、突擊步槍、霰彈槍、狙擊步槍（開鏡），加上空手揮拳；有後座力、連射擴散、動態準星、過肩瞄準。
- **東海美食補血**：雞爪凍（小補）、東海炸雞（中補）、刈包（補滿）、東海冰淇淋（持續回血、小幅加速）。
- **物資與背包**：兩千多件物資散落在每棟建築周圍，依稀有度以顏色區分（灰／綠／藍／紫／金）；背包容量有限，頭盔與防彈背心會吸收子彈傷害並耗損，裝備會穿在角色身上。
- **白天的靶子**：出生點旁的人形靶場，以及 26 座會用雷射鎖定並反擊的哨戒機槍。
- **手機**：虛擬搖桿（推到底衝刺）、右側拖曳轉視角、射擊／瞄準／跳／蹲／換彈按鈕，武器卡與食物可直接點；開始後自動全螢幕並鎖定橫向（iPhone Safari 不支援網頁全螢幕，可「加入主畫面」後開啟）。

網址參數：`?time=22` 從晚上 10 點開始、`?timescale=3` 時間加速、`?touch=1` 在電腦上強制顯示觸控介面。

## 本機執行

不需要安裝 Node.js 或 Python。在 repo 資料夾執行：

```powershell
powershell -ExecutionPolicy Bypass -File serve.ps1
```

然後打開 http://localhost:8080/

## 專案結構

```
index.html            入口頁面、HUD
src/main.js           遊戲主迴圈、光影、鏡頭、介面狀態
src/player.js         角色模型（關節四肢、持槍 IK）、移動、血量
src/input.js          鍵盤、滑鼠、pointer lock
src/items.js          物品定義、稀有度、掉落表（純資料）
src/inventory.js      背包、武器欄、護甲（純邏輯）
src/combat.js         射擊、換彈、補血、撿取
src/targets.js        人形靶、哨戒機槍
src/ghosts.js         女鬼、阿飄（夜間敵人）
src/monsters.js       殭屍、吊死鬼、紅衣小女孩

src/story.js          過去：六樣遺物、結局、籤詩、進度存檔（純資料，可測試）
src/script.js         劇本：開場、章節、手機訊息、伍伯的對話、各章橋段、旁白（純資料）
src/quest.js          導演：每樣東西按下去會怎樣、伍伯在哪、手機何時震動、每章發生什麼
src/world/props.js    互動物件的模型與擺放
src/audio.js          程序化音效（槍聲、尖叫、夜晚環境音）
src/touch.js          手機觸控操作
src/loot.js           地上的物資（空間雜湊，只顯示附近的）

src/fx.js             曳光彈、槍口火光、塵土、傷害數字
src/hud.js            羅盤、小地圖、大地圖、地點名稱

src/world/buildings.js 建築（牆面、窗戶、灰瓦斜屋頂）
```
